## Summary
The dashboard currently relies on hardcoded styling or default Tailwind theme classes. Implement a theme provider in `components/ThemeProvider.tsx` supporting Dark, Light, and High-Contrast (accessibility) themes, with automatic detection of user OS preferences via `prefers-color-scheme` and persistent user selection in `localStorage`.

## Background
See Summary.

## Acceptance criteria
- Supports three modes: "Dark", "Light", and "High-Contrast".
- Toggling theme updates `data-theme` attribute on `document.documentElement` without page reload or layout flickering.
- High-contrast theme strictly satisfies WCAG 2.1 AAA color contrast ratios (≥7:1 for normal text).
- Unit tests verify theme preference initialization, persistence, and media query listener registration.
- Lint, type-check, and tests all pass locally.
- PR description references this issue with `Closes #`.
