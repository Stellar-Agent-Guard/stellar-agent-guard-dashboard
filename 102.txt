## Summary
Organizations requiring multi-signature approval or cold-storage air-gapped signing cannot submit transactions directly through a browser extension. In `lib/guard/submit.ts` and `components/PolicyForm.tsx`, implement an "Export Transaction XDR" option that generates the assembled, simulated Soroban transaction envelope as base64 XDR for offline review and external multi-sig signing tools (e.g. Stellar Laboratory / multisig coordinators).

## Background
See Summary.

## Acceptance criteria
- "Export XDR" button builds the full transaction envelope with simulated footprint and fee prep without requesting wallet signature.
- Displays XDR in a modal with one-click copy and `.tx` file download.
- Includes companion import tool: "Submit Signed XDR" allowing operators to broadcast externally signed envelopes.
- Unit tests test transaction envelope assembly and base64 XDR export.
- Lint, type-check, and tests all pass locally.
- PR description references this issue with `Closes #`.
