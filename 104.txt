## Summary
To accelerate operator workflows during critical incidents, implement a global accessible command palette modal in `components/CommandPalette.tsx` triggered by `Cmd+K` / `Ctrl+K`. The command palette enables quick navigation between panels, instant search across registered guard instances, quick-action execution (e.g. "Trigger Emergency Freeze", "Copy Guard Address", "Export Policy"), and documentation lookup.

## Background
See Summary.

## Acceptance criteria
- Opens on `Cmd+K` (Mac) or `Ctrl+K` (Windows/Linux) and closes on `Escape`.
- Fully keyboard navigable with `ArrowUp`, `ArrowDown`, and `Enter` selection.
- Features fuzzy search across navigation items, guard instances, and administrative actions.
- ARIA attributes: `role="combobox"`, `aria-expanded`, `aria-autocomplete="list"`, `aria-activedescendant`.
- Unit tests verify keyboard event bindings, search filtering, and action dispatching.
- Lint, type-check, and tests all pass locally.
- PR description references this issue with `Closes #`.
