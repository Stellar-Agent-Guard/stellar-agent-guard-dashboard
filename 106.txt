## Summary
Security auditors and compliance officers often require printable physical or PDF summaries of active smart contract guard configurations. Add dedicated CSS print styles (`@media print`) and a "Print Compliance Report" button in `components/StatusPanel.tsx` that formats a clean, paginated audit summary containing Contract ID, Bytecode Verification Hash, Current Policy Rules, Allowlists, Admin Key, and DMS Status with unnecessary UI chrome hidden.

## Background
See Summary.

## Acceptance criteria
- Print view formats cleanly on standard Letter and A4 page dimensions.
- Hides interactive buttons, navigation bars, and theme toggles during print/PDF export.
- Includes timestamp, network name, and full non-truncated Stellar contract addresses.
- Unit tests assert print helper function compiles all required report fields.
- Lint, type-check, and tests all pass locally.
